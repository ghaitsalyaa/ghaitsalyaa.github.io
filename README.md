# 🐧 Kedai Pinguin — Website & Business Rules

Website resmi **Kedai Pinguin** yang mengusung tema *vintage kopitiam* dengan kombinasi warna maroon, coklat tua, coklat muda, krem, dan latar ornamen bunga[cite: 1, 6]. Website ini dilengkapi fitur interaktif daftar menu lengkap, informasi lokasi kedai, dan sistem reservasi meja menggunakan JavaScript & DOM[cite: 1, 23, 28].

---

## 📂 Struktur Berkas (Project Structure)

```text
├── index.html          # Halaman utama (Menu Utama & Daftar Harga)
├── book.html           # Halaman formulir reservasi meja
├── location.html       # Halaman lokasi, kontak, & jam operasional
├── style.css           # Tema tampilan vintage maroon, coklat, & ornamen bunga
├── script.js          # JavaScript global (cek jam buka kedai)
├── book.js            # JavaScript khusus reservasi (validasi form & aturan bisnis)
├── rules.js           # Berkas fungsi aturan bisnis terpisah untuk pengujian Console
